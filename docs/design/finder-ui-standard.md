# Finder UI 设计规范

> 适用范围：本应用桌面端的文件浏览、侧边栏、工具栏、标签页、预览器、任务抽屉与保存 Sheet。  
> 目标：借鉴 macOS Finder 的信息层级、控件节奏与状态反馈；不追求像素级复刻，也不把 Finder 风格等同于“全白 + 蓝色按钮”。

## 1. 核心原则

1. **内容优先**：文件、预览内容和操作结果应是视觉主角；导航与工具只在需要时提供支持。
2. **少而成组**：高频动作直接可达，低频动作进入“更多”菜单。相关控件必须组成按钮组，不做零散图标与文字链接的混排。
3. **状态克制**：系统蓝仅表示当前选中、开启或进行中的主状态；成功、失败、禁用都必须同时以文字和图标表达。
4. **一处一义**：同一动作只有一个主入口；同一图标、尺寸、选中态在所有页面含义一致。
5. **渐进呈现**：详情、完整路径、导出选项、任务历史等次要信息按需展开，不能默认挤占内容空间。

## 2. 基础视觉 Token

| 项目 | 规范 |
| --- | --- |
| 字体 | 系统字体优先：`-apple-system, BlinkMacSystemFont, "SF Pro Text"`；代码/文本内容使用 `SF Mono, Menlo, monospace` |
| 主文字 | 14–15pt；正文/文件列表不可小于 13pt |
| 次级文字 | 12–13pt，使用系统次级灰；不可用过低对比度代替禁用说明 |
| 图标视觉尺寸 | 16–18pt，统一使用 SF Symbols 或同线宽图标库 |
| 图标点击热区 | 常规最小 28×28pt；关键/触控场景最小 32×32pt |
| 工具栏高度 | 文件窗口 44–48pt；预览器工具栏 40–44pt |
| 列表行高 | 侧边栏 32–36pt；任务行 68–76pt；文件列表按视图密度调整 |
| 圆角 | 控件 6–8pt；搜索框/工具栏容器 10–14pt；不使用过大的胶囊形态 |
| 分隔线 | 1px 发丝线；仅用于区域边界或按钮组内部，不把每个分组包成卡片 |
| 主强调色 | macOS 系统蓝，用于激活、选中、主按钮和进行中进度 |

## 3. 工具栏规范

### 3.1 结构

工具栏采用三段布局：

```text
左：当前位置 / 返回前进 / 文件元信息
中：当前页面的主输入（通常是搜索或查找）
右：视图切换 / 高频动作 / 更多
```

- 左、中、右三段之间保留弹性空间；不要把全部控件挤在右上角。
- 同一动作组使用统一浅色材质容器或 1px 内部分隔线，例如：`[网格 | 列表 | 分栏 | 画廊]`。
- 一个组内仅放互斥或相邻动作。复制、导出、历史、方案等不应与搜索框的匹配导航混为一组。
- 窗口窄于 980pt 时，次要文字操作收进“更多”；窄于 840pt 时，搜索可收为图标后打开覆盖式搜索框。控件不可重叠、换行或截断。

### 3.2 按钮状态

| 状态 | 表现 |
| --- | --- |
| 默认 | 透明背景，深灰图标/文字 |
| Hover | 极浅灰圆角底 |
| 按下 | 稍深的灰色背景 |
| 选中/开启 | 系统蓝背景 + 白色图标，或浅灰底 + 蓝色图标/文字；同一组内保持一种规则 |
| 禁用 | 次级灰 + 禁用原因或 Tooltip；不能仅降低到不可读 |
| 危险动作 | 默认不使用红色常驻按钮；放入菜单或确认 Sheet，确认时再使用明确风险文案 |

### 3.3 图标与标签

- 图标优先表达对象类型或操作语义：文件夹、图片、文本、复制、导出、显示于 Finder、任务等。
- 不使用“眼睛”作为一切预览类型的唯一标识；应优先显示图片、文本、PDF 等文件类型图标。
- 图标按钮必须有 Tooltip、无障碍名称和可见键盘焦点。
- 图标 + 文字的主按钮可用于“保存”“完成”等关键动作；其余动作优先使用图标或菜单，避免工具栏出现密集文字链接。

## 4. 搜索与文本预览

### 4.1 搜索框

- 使用位于工具栏中段的 macOS 搜索框：放大镜、查询词、匹配计数、选项、清除。
- 宽度建议 280pt，聚焦时可扩至 320pt；匹配导航使用相邻的上/下箭头按钮。
- `⌘F` 聚焦并全选；`Enter`/`⌘G` 下一个匹配；`⇧Enter`/`⇧⌘G` 上一个匹配；`Esc` 清除并恢复全文。

### 4.2 结果状态

- 搜索必须明确区分“全文高亮”和“仅显示匹配行”。
- 过滤视图显示状态条：`“查询词”：N 个匹配 · 显示匹配行与前后 3 行`，并提供 `显示全文`。
- 连续隐藏内容显示可点击省略块：`⋯ N 行未显示 ⋯`；不能用大块空白表示未显示内容。
- 当前匹配、其他匹配、当前行、用户选区必须使用不同视觉层级。

### 4.3 阅读区

- 文本默认 14–15pt 等宽字体、22–24pt 行高；行号右对齐且可隐藏。
- 类型、行数、文件大小属于左侧弱化元信息，不应与搜索或导出争夺注意力。
- 阅读相关设置包括自动换行、语法语言、字号、行号；复制与导出属于内容操作；高级过滤选项进入搜索 Popover。

## 5. 侧边栏

- 默认宽度 240–280pt，可拖拽；采用连续导航列表，避免“分区卡片化”。
- 以小标题和留白划分收藏、位置、标签等区域；标题 12–13pt 次级灰。
- 默认导航图标使用单色系统图标；仅标签圆点及少量状态使用颜色。
- 选中行优先使用浅灰圆角底 + 蓝色图标与文字；窗口失焦时改为低对比灰色选中。
- 外接卷弹出、共享状态等行尾操作只在 Hover/选中时出现。
- 空的设备分类默认隐藏；“添加设备”应为组内单行入口，不得占据整块区域。
- 设置等低频操作不使用移动端式底部圆形导航，应放进应用菜单、更多菜单或低调设置行。

## 6. 标签页

- 标签表达“打开的位置或预览”，不是浏览器网页标签。
- 标签高度 28–30pt，水平内边距 10–12pt，最小宽 96pt，最大宽 180–200pt。
- 默认标签无边框；Hover 使用浅灰背景；激活标签使用浅灰白材质和 semibold 文字，禁止做成输入框式强白底描边。
- 关闭按钮仅在 Hover 或激活标签显示；有未保存修改时显示小圆点。
- 同名目录必须在 Hover/标签总览中给出完整路径，必要时显示简短父级上下文。
- 标签过多时使用横向滚动或标签总览菜单；不得无限缩小所有标签。
- 支持拖拽排序、右键菜单和 `⌘W` 关闭、`⌘⇧[` / `⌘⇧]` 切换。

## 7. 任务右侧抽屉

- 任务入口位于顶部工具栏右侧，显示任务数或总体进度 Badge。
- 任务面板从**右侧**展开，默认宽 320–360pt，可调整至 280–440pt；不影响左侧导航。
- 空闲且无失败任务时默认关闭；完成任务只保留在历史中，不常驻占用文件浏览空间。
- 抽屉头部为 `任务` + `进行中` / `历史` 分段控件；历史视图才显示“清除历史”。
- 任务使用连续列表而非大灰卡：操作图标、标题、状态摘要、细进度条、行尾动作。
- 路径默认只显示短摘要；完整路径通过展开详情或更多菜单查看。
- 成功、失败、暂停均需图标和文字，不能只靠绿/红色。

## 8. Sheet、弹窗与保存

- 优先使用实色 macOS Sheet；表单内容不可被背景图片或页面文字穿透。
- 标题清楚描述结果，例如“保存标注后的图片”；主按钮文案随操作变化，例如“存储副本”“替换并保存”。
- 默认优先安全操作：导出副本；覆盖原文件必须有明确风险提示和二次确认。
- 高级导出选项使用 disclosure 展开；只有格式支持时才启用品质、压缩、缩放等控件。
- `取消` 与主按钮右对齐，均为统一 32pt 高度；禁用与错误反馈必须清晰。

## 9. 可访问性与交互质量

- 全部可操作控件可通过键盘访问，焦点清晰可见。
- 不把颜色作为唯一状态信号；成功、失败、选择、同步等均包含文字或图标。
- Tooltip 说明图标的动作，而不是重复图标名称。
- 窗口缩小时优先隐藏低频功能，不挤压核心路径、查找、复制、保存或任务入口。
- 长文件名、路径、错误信息采用省略号，并通过 Tooltip、展开详情或辅助功能提供完整文本。

## 10. 评审清单

上线前逐项确认：

- [ ] 同一层级的图标尺寸、热区、圆角和 Hover 状态一致。
- [ ] 工具栏按操作分组，且任意宽度下不存在重叠、换行或截断。
- [ ] 选中态与进行中态不滥用系统蓝。
- [ ] 空状态、完成状态与失败状态不会长时间挤占主内容。
- [ ] 所有图标操作都有 Tooltip、键盘焦点和无障碍名称。
- [ ] 同名标签、长路径和大量任务都能快速辨别。
- [ ] 低频设置进入 Popover/更多菜单，而非长期堆在主界面。

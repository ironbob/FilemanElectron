# 目录对比功能设计规范

## 1. Beyond Compare 交互分析

### 1.1 整体布局

Beyond Compare（以下简称 BC）的目录对比采用**左右双栏布局**，两侧各显示一棵目录树，中间通过对齐行呈现文件的对应关系。

```
┌──────────────────────────────────────────────────────────┐
│  [工具栏: 同步/复制/删除/过滤/比较规则]                     │
├──────────────────┬───────────────────────────────────────┤
│  左侧路径选择框   │  右侧路径选择框                         │
├──────────────────┴───────────────────────────────────────┤
│  列头: 名称 | 大小 | 修改时间 || 名称 | 大小 | 修改时间     │
├──────────────────────────────────────────────────────────┤
│  file_a.txt  12KB  2024-01  │  file_a.txt  14KB  2024-02  │  ← 内容不同
│  file_b.png  80KB  2024-01  │  file_b.png  80KB  2024-01  │  ← 相同
│  old_log.txt 4KB   2023-06  │  (空)                       │  ← 仅左侧有
│  (空)                       │  new_doc.pdf 22KB  2024-03  │  ← 仅右侧有
│  ▶ subdir/                  │  ▶ subdir/                  │  ← 子目录
└──────────────────────────────────────────────────────────┘
│  状态栏: 差异 3 | 相同 1 | 仅左侧 1 | 仅右侧 1             │
└──────────────────────────────────────────────────────────┘
```

### 1.2 文件状态分类与颜色编码

BC 根据两侧文件的属性将每一行归为以下状态，并以颜色区分：

| 状态 | 符号 | BC 默认颜色 | 说明 |
|------|------|-------------|------|
| **相同 (Equal)** | `=` | 无高亮（白/灰行） | 两侧文件名、大小、时间戳（或内容哈希）完全一致 |
| **内容不同 (Different)** | `≠` | 红色行背景 | 文件在两侧均存在，但内容或大小不同 |
| **左侧较新 (Left Newer)** | `◄` | 蓝色行背景 | 文件在两侧均存在，左侧修改时间更新 |
| **右侧较新 (Right Newer)** | `►` | 蓝色行背景（深） | 文件在两侧均存在，右侧修改时间更新 |
| **仅左侧有 (Left Only)** | `◄◄` | 橙/黄色行背景（左列） | 文件只在左侧目录存在 |
| **仅右侧有 (Right Only)** | `►►` | 橙/黄色行背景（右列） | 文件只在右侧目录存在 |
| **已排除 (Excluded)** | `○` | 灰色文字 | 被过滤规则忽略的文件 |
| **子目录（有差异）** | `▶≠` | 文件夹图标 + 状态色 | 子目录内部存在差异 |
| **子目录（相同）** | `▶=` | 文件夹图标，无高亮 | 子目录内部完全相同 |

### 1.3 工具栏功能

```
[←复制到左] [→复制到右] [删除] | [展开全部] [折叠全部] | [显示: 全部▼] [比较规则▼] | [刷新]
```

#### 复制 / 同步操作
- **复制到右侧 (Copy Right)**：将选中文件从左侧复制到右侧相同相对路径
- **复制到左侧 (Copy Left)**：将选中文件从右侧复制到左侧相同相对路径
- **镜像左→右 (Mirror Left to Right)**：以左侧为基准，使右侧与左侧完全一致（删除右侧多余文件、覆盖不同文件）
- **镜像右→左 (Mirror Right to Left)**：反向镜像
- **双向同步 (Sync)**：按规则（取较新者）双向合并

#### 过滤显示
BC 提供快速切换按钮，控制哪些状态行可见：

| 过滤项 | 说明 |
|--------|------|
| 显示相同 | 隐藏/显示 Equal 行 |
| 显示差异 | 隐藏/显示 Different/Newer 行 |
| 显示孤立 | 隐藏/显示 Left Only / Right Only 行 |

常用预设：**"仅显示差异"** = 隐藏 Equal，只保留需要处理的行。

#### 比较规则
- **按名称**：仅配对同名文件，不比较内容
- **按大小**：相同名称且大小一致则视为相同
- **按时间戳**：相同名称且修改时间一致（精确到秒或分钟）则视为相同
- **按内容（慢）**：计算 CRC/哈希，内容完全相同才标为 Equal

### 1.4 行交互

- **单击行**：选中该行（两侧同步高亮）
- **双击文件行**：若文件在两侧均存在，打开文件内容对比窗口（Diff 视图）
- **双击目录行**：展开/折叠子目录
- **Shift/Cmd 多选**：同 Finder/文件管理器多选逻辑
- **右键菜单**：
  - 复制到右侧 / 复制到左侧
  - 删除（左侧 / 右侧 / 两侧）
  - 对比内容（仅文件）
  - 排除此文件/类型
  - 属性/信息

### 1.5 目录展开与递归

- 默认展开一层；点击 `▶` 折叠/展开子目录
- 子目录行显示汇总状态（子树内是否有差异）
- 工具栏"展开全部"展开整棵树，"折叠全部"收起到根层

### 1.6 状态栏

始终显示当前视图的汇总统计：
```
差异: 5   左仅有: 3   右仅有: 2   相同: 47   已排除: 0   总计: 57
```

### 1.7 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `F5` | 刷新对比 |
| `F7` | 下一差异 |
| `Shift+F7` | 上一差异 |
| `→` / `←` | 复制到右侧 / 左侧（选中行） |
| `Del` | 删除选中 |
| `Space` | 展开/折叠当前目录行 |

## 2. FilemanElectron 目录对比功能设计

### 2.1 功能触发方式

**触发条件**：用户在文件列表中选中 **2 个目录**（均为 `isDirectory: true`），右键菜单底部出现"对比目录"选项。

**右键菜单项**（仅当选中恰好 2 个目录时出现）：
```
─────────────
对比目录        ⌘⇧D
─────────────
```

单击"对比目录"后，在主区域新建一个"目录对比视图"标签页，两侧分别显示选中的两个目录。

> **备选触发方式**：左侧窗格选中 1 个目录，右侧窗格选中 1 个目录，点击顶部"对比"按钮（跨窗格对比）——此方式作为 v2 扩展。

### 2.2 组件架构

```
src/components/compare/
├── DirCompareView.vue          # 主视图容器（路由/标签页级）
├── DirCompareToolbar.vue       # 顶部工具栏
├── DirComparePane.vue          # 单侧目录列（左 or 右），复用布局
├── DirCompareRow.vue           # 单行：左侧文件列 + 状态指示 + 右侧文件列
├── DirCompareStatusBar.vue     # 底部统计栏
└── composables/
    └── useDirCompare.ts        # 对比逻辑、状态管理
```

### 2.3 视图布局

```
┌─────────────────────────────────────────────────────────────────┐
│  DirCompareToolbar                                               │
│  [← 复制] [复制 →] [删除] │ [展开] [折叠] │ [过滤▼] [规则▼] [刷新] │
├──────────────────┬──────────────────────────────────────────────┤
│  左侧路径（只读）  │  右侧路径（只读）                              │
├──────────────────┴──────────────────────────────────────────────┤
│  名称        大小    修改时间  │ 状态 │ 名称        大小    修改时间  │
│─────────────────────────────────────────────────────────────────│
│  (虚拟滚动列表，每行对齐)                                          │
├─────────────────────────────────────────────────────────────────┤
│  DirCompareStatusBar: 差异 x | 左仅有 x | 右仅有 x | 相同 x      │
└─────────────────────────────────────────────────────────────────┘
```

### 2.4 数据模型

```typescript
// 比较规则
type CompareRule = 'name' | 'size' | 'timestamp' | 'content'

// 单个文件的对比条目
interface CompareEntry {
  status: 'equal' | 'different' | 'left-newer' | 'right-newer' | 'left-only' | 'right-only'
  relativePath: string      // 相对于各自根目录的路径（作为对齐 key）
  left?: FileInfo           // 左侧文件信息（absent 时为 undefined）
  right?: FileInfo          // 右侧文件信息（absent 时为 undefined）
  children?: CompareEntry[] // 子目录内容（懒加载）
  isDirectory: boolean
  expanded: boolean
}

// 对比会话状态
interface DirCompareSession {
  id: string
  leftDeviceId: string
  leftPath: string
  rightDeviceId: string
  rightPath: string
  rule: CompareRule
  filter: {
    showEqual: boolean
    showDifferent: boolean
    showLeftOnly: boolean
    showRightOnly: boolean
  }
  entries: CompareEntry[]
  isLoading: boolean
  stats: {
    equal: number
    different: number
    leftOnly: number
    rightOnly: number
    total: number
  }
}
```

### 2.5 颜色与视觉规范

遵循现有 Tailwind 设计 token，与全局暗色主题一致：

| 状态 | 行背景色 | 文字颜色 | 状态图标 |
|------|----------|----------|----------|
| Equal | 无（透明） | `text-text-primary` | `=` `text-text-tertiary` |
| Different | `bg-red-500/10` | `text-text-primary` | `≠` `text-red-400` |
| Left Newer | `bg-blue-500/10` | `text-text-primary` | `◄` `text-blue-400` |
| Right Newer | `bg-blue-500/10` | `text-text-primary` | `►` `text-blue-400` |
| Left Only | 左列 `bg-orange-500/15`，右列空白 | `text-text-primary` | `◄◄` `text-orange-400` |
| Right Only | 左列空白，右列 `bg-orange-500/15` | `text-text-primary` | `►►` `text-orange-400` |

状态图标居中显示于两列之间的 **24px 宽指示列**。

### 2.6 过滤栏设计

工具栏内置 4 个切换按钮（SegmentedControl 风格）：

```
[ 全部 ] [ 差异 ] [ 孤立 ] [ 相同 ]
```

- **全部**：显示所有行
- **差异**：仅显示 different / left-newer / right-newer
- **孤立**：仅显示 left-only / right-only
- **相同**：仅显示 equal

### 2.7 操作行为

#### 复制
- **复制到右侧**：将左侧文件按相对路径复制到右侧目录；若目标存在则覆盖
- **复制到左侧**：反向操作
- 操作通过现有 `fileOpsStore.createCopyTask()` 执行，完成后局部刷新该行状态

#### 删除
- 弹出确认对话框，明确标注"将从 **左侧/右侧/两侧** 删除以下文件"
- 通过 `fileOpsStore.createDeleteTask()` 执行，完成后移除该行

#### 刷新
- 重新执行当前目录对比，保留展开/折叠状态

#### 导航到差异
- 工具栏"下一差异 ▼"/"上一差异 ▲"按钮，跳转至下一个非 equal 行
- 快捷键：`F7` / `Shift+F7`

### 2.8 右键菜单（对比视图内）

点击某行的右键菜单：
```
复制到右侧
复制到左侧
────
在左侧窗格中打开
在右侧窗格中打开
────
删除（左侧）
删除（右侧）
删除（两侧）
────
对比内容…       （仅文件，status=different/newer时可用）
```

### 2.9 性能考虑

- **懒加载子目录**：初始只比较根级内容，展开子目录时按需加载
- **虚拟滚动**：使用 `RecycleScroller`，行高固定 40px，与 FileList 一致
- **增量刷新**：操作后只刷新受影响的条目，不重新对比整棵树
- **大目录提示**：超过 10,000 个文件时显示警告，提示启用"仅按名称"规则

### 2.10 与现有系统的集成点

| 集成点 | 方案 |
|--------|------|
| 触发入口 | `FileList.vue` `buildContextMenuItems()` 中判断 `selectedFiles.length === 2 && 两者均为 dir` 时追加"对比目录"项 |
| 标签页系统 | `tabsStore` 新增 pane type `'compare'`，携带 `DirCompareSession` |
| 文件操作 | 复用 `fileOpsStore` 的 copy/delete task |
| 设备适配 | 左右两侧可各自指定 deviceId，支持跨设备目录对比（同设备为主，跨设备为 v2） |
| 样式 | 完全使用现有 Tailwind CSS 变量（`bg-bg-primary`、`text-text-primary` 等）、暗色主题 |

## 3. v1 范围界定

### v1 包含
- [x] 同设备两目录对比
- [x] 按名称 / 大小 / 时间戳 三种比较规则
- [x] 颜色编码 + 状态指示列
- [x] 过滤（差异/孤立/相同/全部）
- [x] 复制到左/右、删除（单侧）
- [x] 子目录懒加载展开
- [x] 虚拟滚动
- [x] 统计栏
- [x] 下一差异/上一差异导航

### v1 不包含（留待 v2）
- [ ] 按内容（CRC/哈希）比较（需 main process 计算）
- [ ] 跨设备目录对比
- [ ] 文件内容 Diff 视图联动（双击打开 text diff）
- [ ] 双向同步 / 镜像一键操作
- [ ] 对比结果导出（HTML / CSV）
- [ ] 保存 / 恢复对比会话

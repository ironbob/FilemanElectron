# 双目录文件操作：交互与界面规划

## 目标

在一个工作区同时呈现左、右两个独立目录，用户可将一侧选中的文件或文件夹拖到另一侧完成复制。

## 已确认的界面契约

- 双目录并排显示，各自拥有独立的目录位置和内容列表。
- 支持从任一侧向另一侧拖放复制文件或文件夹。
- 目录路径控件、导航按钮、列表字段、冲突处理、进度和错误呈现尚未指定；实施前须作为产品决策补充，不能把它们当作已确认视觉细节。

## 推荐交互

1. 用户在源目录选择一个或多个文件/文件夹并开始拖动。
2. 另一目录面板显示明确的可投放高亮，并保持目标路径可识别。
3. 松开后创建复制任务；复制不阻塞继续浏览。
4. 若目标同名，显示冲突决策：跳过、替换、保留两者，以及应用到全部。
5. 任务区域提供进度、完成结果、失败原因与重试入口。

## 实施影响与边界

- 当前项目已有 `FilePane`、内部拖放复制及任务队列；新增双目录工作区需要补齐“创建/切换第二面板”、面板活跃态和面板间目标识别。
- 文件复制逻辑、后台任务、冲突策略和跨设备权限会影响状态与数据流，不属于单屏纯 UI；若要实施，必须先显式调用 `$arch-first-code-gen`。
- 本轮仅完成界面与交互规划，未修改生产代码，也没有声称完成视觉渲染或功能验收。

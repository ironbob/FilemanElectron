# Finder 风格主窗口还原报告

## 结果

- 模式：repair。
- 已实现：Finder shell、浅色窗口 chrome、紧凑工具栏、侧边栏、单标签连续内容视图、Finder SVG registry，以及分享路径和标签编辑入口。
- 代码验证：`npm run typecheck` 与 `npm run build` 均通过。
- 架构验证：设计契约、架构文档和架构三门校验均通过。

## 视觉证据

已使用用户确认的 SHOT-01（1920×1001）与 Electron 实际渲染（1152×768）进行人工视觉对比。未生成同尺寸像素 diff，因此没有将视觉差异写为 `matched`。

本轮收敛了三项可量取差异：单标签页不再展示额外标签栏；侧边栏宽度从 208px 调整到 176px，和参考比例的偏差为 3.63%；列表改为 Finder 的“名称 / 修改日期 / 大小 / 种类”列序，并将行高收紧到 26px。

## 已交付入口与图标

- 工具栏包含后退、前进、视图模式、复制选中路径以分享、编辑选中项标签、搜索和排序入口。
- 位置、设备与收藏导航保留既有数据绑定，外观进入 Finder scoped UI Kit。
- 18 个语义图标均为 Lucide ISC SVG，资源文件、检索 URL、许可证和代码引用已记录在 assets-manifest.json。

## 标红项

- DIM-02、DIM-05：顶部 chrome 和列表行高仍与参考图有可量取残差。
- STATE-02、STATE-03：当前选中行是蓝色而参考为中性灰；空状态没有参考图。
- MISMATCH-01 至 MISMATCH-06：结构、工具栏、侧边栏、样式、图标与状态的残余差异已记录在 repair-audit.json，未被误报为完全匹配。

## 后续视觉闭环

如需像素级收敛，应以 1920×1001 同尺寸、浅色主题重拍应用窗口，再继续压缩顶部 chrome 和列表行高，并把应用专用侧栏分组/工具项合并到 Finder 对应的溢出入口。

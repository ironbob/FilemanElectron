# 内容搜索 + 哈希链（校验和 / 重复查找 / grep）功能需求文档（M3）

> 日期：2026-08-15 ｜ 状态：已确认（随「程序员工作台功能套件」总体规划批准）
> 产出模式：总体规划之 M3 套件（F6 校验和 + F8 重复文件查找 + F1 grep 内容搜索）

## 1. 一句话目标

为开发者提供"哪个文件里有这个字符串"的内容搜索、下载/发布包哈希校验与对比、以及按内容找出重复文件回收空间——三条围绕文件内容的高频排查链路。

## 2. 背景与成功标准

- 当前问题：`fs:search` 只搜文件名；校验和要开终端跑 shasum；重复文件靠肉眼或第三方工具，且都无法覆盖远程设备。
- 成功标准：① 右键目录即可按内容/正则/glob 搜索，点击命中直达预览行号；② 选 1-2 个文件右键算 MD5/SHA1/SHA256 并对比（可跨设备）；③ 一键扫描目录找重复，勾选旧副本批量删除。

## 3. 用户与角色

| 角色 | 可以做 | 明确不能做 |
|---|---|---|
| 开发者 | 内容搜索（本地/SSH/Android/SMB/WebDAV）、哈希校验对比、重复查找与批量删除 | iOS 设备上使用这三项（canGrepContent=false 等能力门控） |

## 4. 核心场景

- 场景 1：在项目根右键「在此搜索内容…」→ 输 `TODO_FIX` → 按文件分组命中流式到达 → 点击命中行 → 预览打开并定位该行。
- 场景 2：下载 ISO 后选本地与备份两份 → 右键「校验和对比」→ SHA256 一致绿条/不一致红条。
- 场景 3：备份目录右键「查找重复文件…」→ 三阶段漏斗 → 「勾选旧副本」→ 删除走文件操作队列可撤销查看。

## 5. 业务对象与术语

| 术语 | 定义 |
|---|---|
| 引擎矩阵 | grep 按设备分流：本地+rg → ripgrep 子进程；SSH/Android → 远端 exec grep；SMB/WebDAV/本地无rg → 流式逐行扫描 |
| 命中（GrepMatch） | path + 行号 + 列 + 行文本（截 400 字）+ 高亮区间 |
| 三阶段漏斗 | 重复查找：size 分组 → 4KB 首块哈希 → 全量哈希；每阶段大幅收敛候选 |
| 可回收空间 | Σ 组大小 ×（组内文件数 - 1） |
| 终态必达 | completed/cancelled/failed 事件绕过节流（lastEmitAt=0）必发 |

## 6. 业务规则

- R1（只读搜索）：grep 与校验和全程只读；重复查找仅在读后由用户显式删除（走既有删除队列）。
- R2（能力门控）：iOS 无内容搜索（无 exec 无流式）；菜单与入口按 canGrepContent 隐藏。
- R3（会话取消）：同 sessionId 重开自动取消旧任务；UI 取消即时（协作标志 + 杀子进程/销毁流）。
- R4（上限）：grep 默认 10000 命中（截断置 truncated）；重复分组终态 ≤5000 组 + truncated；行文本截 400 字。
- R5（批量推送）：grep 命中按 100ms/200 条批量增量推送；dupes 分组只随 completed 终态下发。
- R6（安全构造）：远端命令一律 shellQuote 单引号包裹；execFile/spawn 参数数组不经 shell。
- R7（入口一致）：三个功能均可从右键菜单进入；grep/dupes 是瞬态工具页标签；checksum 是弹窗。

## 7. 功能清单

#### 模块 A：校验和（F6）
| 优先级 | 功能 | 验收 |
|---|---|---|
| P0 | 单文件哈希（md5/sha1/sha256 可切） | 结果可复制；进度字节级 |
| P0 | 两文件对比（含跨设备） | 终态绿/红横幅 match 结论 |

#### 模块 B：重复查找（F8）
| 优先级 | 功能 | 验收 |
|---|---|---|
| P0 | 三阶段扫描 + 分组折叠列表 | 组头显示文件数/单件大小/冗余量；可回收总量正确 |
| P0 | 勾选旧副本 + 批量删除 | 每组保留最新；删除走 fileOperations 队列 |

#### 模块 C：grep（F1）
| 优先级 | 功能 | 验收 |
|---|---|---|
| P0 | 查询栏（正则/大小写/包含/排除 glob）+ 流式分组结果 | 批量增量渲染；状态行实时命中数 |
| P0 | 点击命中 → 预览定位行号 | Monaco revealLineInCenter + 选中行 |
| P1 | rg 捆绑（extraResources）+ $PATH/流式回退 | 三级引擎矩阵按可用性自动选择 |
| P1 | 命令面板注册「重新执行搜索」 | 挂载注册/卸载注销 |

## 8. 关键异常

| 场景 | 期望 |
|---|---|
| rg 不存在 | 自动降级流式引擎（不报错） |
| 远端 grep exit 1 | 零匹配，非错误 |
| 二进制文件（流式引擎） | 首 8KB 含 NUL 跳过 |
| 单文件读失败（哈希阶段） | 跳过该候选并日志，不中止任务 |
| SMB 无 exec 且文件 >5MB | 流式引擎跳过大文件（成本护栏） |
| 命中超上限 | 截断标志 + UI 明示 |

## 9. 约束

- 复用 M1 共享基建（SessionTaskRegistry/DirectoryWalker/hashAdapterFileRange/useLongTaskProgress/ToolPathResolver）——不重写遍历/哈希/任务骨架。
- 长任务全部走「同 session 取消旧任务 + 终态必达」既有模式。
- `.ts` 等扩展名在通用分类器是视频（MPEG-TS）——grep 命中跳转时 initialLine 强制按文本渲染。

## 10. 明确不做

- 不做 grep 的替换/批量重构（sed 域）；不做跨设备重复查找（单设备扫描）；不做 checksum 的哈希文件校验（.sha256 文件解析）。
- 不做 inotify/fsnotify 远端推送（远端 grep 已是远端执行）。

## 11. 假设与风险

- 假设：远端为 GNU grep（--include/--exclude 支持）；BSD/macOS 远端少见，不支持时 exclude 失效可接受。
- 假设：4KB 首块 + 同尺寸已足以在阶段 2 分离绝大多数非重复内容。
- 风险：超深目录的流式引擎慢（无 rg 的 SMB）——已有 5MB/文件护栏 + 取消；真实体验待设备联调。
- 风险：rg 二进制未捆绑前依赖 $PATH——用户无 rg 时本地也走流式（功能可用但慢）。
